Jal Sahay — Water Complaint Management Portal

A full complaint lifecycle system for water-related civic issues, built with FastAPI, SQLAlchemy, SQLite and Jinja2. Four distinct roles — Citizen, Officer, Field Worker, and Admin — move a complaint through a defined state machine from report to resolution.

Auth runs on JWTs stored in httponly cookies. Citizens can attach photo evidence, processed through Pillow before storage. After a security pass, public registration was locked to Citizen-only, and an admin bootstrap CLI script was added so admin accounts are never created through the open signup flow.

FastAPI SQLAlchemy SQLite Jinja2 JWT / httponly cookies Pillow

NeedBro — Home Services Marketplace

An UrbanClap / Sulekha-style marketplace connecting customers with home service providers, backed by FastAPI, SQLAlchemy and MySQL across roughly 20 database tables and three roles: customer, provider, and admin.

Real-time chat between customers and providers runs over WebSockets. The frontend is 18 hand-built HTML/CSS/JS pages with clean, readable URL routing — no framework scaffolding, just structured routes and templates. Along the way, I worked through several Windows/PowerShell-specific environment issues that don't show up in most tutorial setups.

FastAPI SQLAlchemy MySQL WebSockets HTML / CSS / JS
